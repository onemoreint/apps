# Android Control Center (panel demo compilado)

Esta carpeta contiene solo el panel ya compilado que publica GitHub Pages en
https://onemoreint.github.io/apps/android-control-center/

El código fuente completo (panel, agente Android, backend, documentación) está en la rama
[`android-control-center`](https://github.com/onemoreint/apps/tree/android-control-center).
Para actualizar: compila `web/` con `VITE_BASE=/apps/android-control-center/ npm run build`
y reemplaza el contenido de esta carpeta, o descarga el artefacto `panel-web` del flujo Web.
