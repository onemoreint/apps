# Jack -- 3D Creator Portfolio

Landing page built with React, TypeScript, Tailwind CSS, Framer Motion, Lucide React, and the Kanit Google Font.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Structure

```txt
jack-3d-creator/
  index.html
  package.json
  tailwind.config.js
  postcss.config.js
  vite.config.ts
  tsconfig.json
  src/
    App.tsx
    index.css
    main.tsx
```

## Notes

The page uses external image and GIF URLs, so the final visual preview requires internet access in the browser.
