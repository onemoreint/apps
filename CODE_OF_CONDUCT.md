# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: tratamos a todas las personas con respeto, aceptamos las críticas constructivas y no toleramos acoso, insultos ni ataques personales. Las personas mantenedoras pueden eliminar contenido o bloquear a quien incumpla estas normas.

Para reportar un problema de conducta, escribe a las personas mantenedoras mediante un aviso privado en GitHub.
