🔒 Privacidad

      
    

    

      

        Lo que se guarda en este teléfono o computador (almacenamiento local del navegador):
        
    
          
  • Tu carrito y tu último pedido (solo qué productos y cuántas unidades), para no perderlos y poder repetirlos.
    • 
          
  • Tu nombre, torre/apartamento y modalidad de entrega solo si marcas "Recordar mis datos". Si lo desmarcas, se borran.
    • 
          
  • Si eres el dueño y editas la tienda aquí, la configuración del catálogo.
    • 
        

      

      

        Lo que NO se guarda:
        
    
          
  • Tus observaciones ni el método de pago que eliges.
    • 
          
  • Ningún dato bancario ni de tarjetas. Esta página no cobra ni procesa pagos.
    • 
        

      

      

        A dónde van tus datos:
        
Esta página no envía tus datos a ningún servidor. El pedido solo sale cuando tú lo envías desde WhatsApp, y desde ese momento aplican las políticas de WhatsApp.
          El sitio donde esté publicada la página (por ejemplo, GitHub Pages) puede registrar datos técnicos de visita, como cualquier sitio web.

      

      

        Lo guardado en el navegador no se sincroniza entre dispositivos y se borra si limpias los datos del navegador.
