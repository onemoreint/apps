# MOLDERA 360 — Del diseño a la moldería.

Plataforma de diseño y moldería paramétrica para marroquinería: **bolsos, billeteras y morrales**.

- Parámetros → motor geométrico (mm) → moldes SVG con corte, costura y piquetes.
- Despiece, ficha técnica, visor interactivo.
- Impresión a escala 100 % con mosaico, marcas de alineación y calibración 50 × 50 mm.
- Exportación SVG 1:1, proyectos JSON, biblioteca local (localStorage).
- «Diseñar con IA»: intérprete local de lenguaje natural → parámetros (sin servidor).

Uso: abrir `index.html` en el navegador. No requiere instalación ni backend.
