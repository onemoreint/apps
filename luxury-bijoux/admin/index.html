¿Cómo creo el token?
  1. En GitHub abre Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Elige Only select repositories y marca solo el repositorio del sitio.
  3. En Repository permissions da a Contents el permiso Read and write.
  4. Ponle una fecha de vencimiento y copia el token aquí.

Importación masiva

Sube un archivo CSV o JSON. Las filas con un id existente actualizan ese producto; las demás crean productos nuevos. Columnas: id, nombre, referencia, categoria, coleccion, medidas, precios, descripcion, caracteristicas, imagenes, destacado, novedad, oculto, agotado. Separa varias medidas, precios o imágenes con |.
