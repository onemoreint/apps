📘 Manual de uso

Dónde se aprovecha FreeLLMAPI

Este HTML usa una sola URL compatible con OpenAI. Si esa URL apunta a FreeLLMAPI, el panel puede enviar solicitudes a múltiples proveedores desde un solo lugar.

Además, incluye perfiles de modelos, fallback, multiagentes, generación masiva y CRM con mensajes inteligentes.

Cómo conectarlo

1. Monta FreeLLMAPI en un servidor, VPS, Render, Railway, Replit, Cloudflare o similar.

2. Copia el endpoint /v1/chat/completions.

3. Pégalo en Configuración FreeLLMAPI.

4. Coloca los modelos disponibles o usa auto.

Reglas de seguridad comercial

No prometas curas, resultados médicos ni ingresos garantizados. Usa lenguaje de bienestar, educación, curiosidad y oportunidad responsable.
