Conexión

Para publicar los cambios en la tienda, pega tu token de GitHub. Se guarda solo en este navegador. Sin token puedes revisar precios y descargar el archivo, pero no publicar.

¿Cómo creo el token?
  1. Entra a github.com/settings/personal-access-tokens/new.
  2. En Resource owner elige onemoreint; en Repository access, «Only select repositories» → apps.
  3. En Permissions → Repository → Contents elige Read and write. Ponle vencimiento (por ejemplo 90 días) y créalo.
  4. Copia el token y pégalo aquí. Si la organización exige aprobación, apruébalo en GitHub.
